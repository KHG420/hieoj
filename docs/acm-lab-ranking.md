# ACM 实验室与最近一年排名

## 排名

`ranklist.php` 默认 `range=year`，按服务器日期向前一年起至当前时间的提交统计。`range=all` 沿用用户历史 solved/submit 统计。最近一年只统计 problem_id > 0 的提交，同题多次 AC 只计一个通过题目；较早通过、最近一年再次 AC 的题目计入最近一年。提交次数与相似度统计使用同一时间范围。排序继续为通过数降序、提交数升序、注册时间升序。筛选和分页保留范围，不改变历史提交或金币。

## 实验室入口

首页提供了解实验室、加入我们、发现 Bug、意见建议；用户菜单提供“我的申请与反馈”。管理后台侧栏提供“ACM 实验室管理”，也可以访问 `lab.php?tab=manage` 和 `lab.php?tab=settings`。

- 介绍与联系方式按纯文本展示，管理员可修改并控制招新开关。默认介绍不包含未经确认的活动、地点或联系方式，管理员应补充实际安排。
- 登录用户提交加入申请。待处理、沟通中的申请可更新原记录；已通过的用户不能重复申请。关闭招新时禁止新提交和申请修改，仍可查看已有进度。
- 问题与功能建议共用反馈模块，分别收集复现信息和建议内容。用户可查看自己的记录、当前状态、管理员最新回复及更新时间。
- 管理员可按类型和状态筛选，修改状态、回复用户、添加仅管理员可见的内部备注。变更状态时必须提供回复。
- 申请、反馈正文与截图只对本人和管理员开放。所有写操作校验登录与 CSRF。文本输出转义；截图通过鉴权路由读取，不放在公开上传目录。
- 每条反馈可附一张 2 MB 以内的 PNG/JPEG/WebP 图片，校验实际格式与尺寸，保存在该反馈的数据库记录中。数据库备份因此也包含私有截图，应按私有资料管理。

## 数据库升级

先备份现有数据库，再以有建表权限的账号在业务数据库执行 `docker/db/acm-lab.sql`，然后构建并重建 Web 服务。

脚本只增加 `acm_lab_settings` 和 `acm_lab_request`，可重复执行，不修改现有用户/提交/金币表。新安装由数据库 entrypoint 自动初始化；已有数据库必须显式执行增量脚本，不需要重建或重启数据库。

回滚应用可使用旧 Web 镜像；保留新增表，避免丢失已经收集的申请与反馈。
