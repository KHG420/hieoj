# 今日冒险

入口：主页「今日冒险」、个人菜单，以及知识地图中的「开启三题远征」。本人用户主页可打开解题回忆录。

| 玩法 | 使用方式与判定 |
| --- | --- |
| 昨日之敌 | 每天选一道昨天及以前失败过、尚未通过的公开题；当天选中的题通过后保留翻盘战报，可下载 PNG。 |
| 算法远征 | 选择知识点与挑战/巩固模式，固定三道题，包含所选知识点并参考前置节点；本轮开始后提交的练习 AC 点亮路标，三题通过可下载通关卡。 |
| 影子挑战 | 从最近 50 场符合参与条件的已结束公开比赛中，选择题目仍可公开练习的一场；按原比赛时长计时，对比同一时刻的通过数、首题时间和错误提交。复练通过普通练习入口提交，不写入原比赛成绩。 |
| 反例猎人 | 三个内置 C++ 片段：最大值初始化、二分边界、贪心找零；服务器限制输入并计算错误输出与正确输出，不执行用户提供的代码。按周轮换默认挑战，也可自由选题。 |
| 校园共同挑战 | 每周从当前公开题库确定五题，全站共同完成 100 次首次通过。每个用户/题目只计一次，首次 AC 必须发生在本周练习中；之前已 AC 或首次 AC 来自比赛的不计入。 |
| 解题回忆录 | 按月查看公开题目的活跃天数、通过题数、AC 使用语言数及翻盘记录，可下载 PNG。仅本人可见。 |

## 数据与边界

- 不增加生产依赖、数据库表或迁移，不改变现有判题协议。
- 统一排除隐藏题、私有比赛题及未结束公开比赛题，包括管理员访问。
- 推荐和统计只使用当前公开题。题目可见性改变后，校园题单及历史汇总可能调整。
- 远征路线按“用户 + 日期”保存在服务端，当天固定：再次提交或换设备登录都会回到同一组三题、同一开始时间和同一提交编号边界，不会重新计时。只有路线中的题目不再公开或已不存在时，页面才提供「重新生成今日路线」，按当前选择的知识点换一组合法题目，并把开始时间与提交游标一起移到替换时刻；同一请求重复提交不会再次替换。被下架或删除的题目只显示为“已不可用”，不再带出标题。每日 10 金币仍以当天账本去重，替换路线不会产生第二次奖励。
- 每日路线的读取与修复只发生在「算法远征」标签页：路线表不可用或记录异常时，只有该标签页显示错误，「反例猎人」「影子挑战」等其他玩法的状态保存与跳转不受影响。
- 路线每站的所属知识点按当前知识地图还原：三题可能分别来自目标知识点和它的前置知识点，各站显示各自的知识点名称，而不是统一标成目标节点。
- 影子计时、当日旧题选择和反例挑战标记保存在当前登录会话。退出登录或会话过期会清除这些状态；真实提交记录仍按原系统保存。不同设备不共享本轮计时。
- 开始远征/影子挑战时记录提交编号边界，同一秒内较早提交或开始前仍在排队的代码不会算入本轮。
- 练习题在新标签页打开，回到冒险页点击「刷新判题进度」更新结果。影子计时器自动走时，成绩由服务器重新加载时更新。
- 周一零点切换校园题单，使用站点 PHP/数据库既有的 Asia/Shanghai 时区。
- 反例猎人当前提供三个内置挑战，无后台出题或跨会话排行榜；PNG 卡片下载到本机，不自动发布。

## 验证

纯逻辑与知识地图回归：

```sh
docker compose exec -T -u www-data web php /home/judge/src/web/tests/adventure_test.php
docker compose exec -T web php /home/judge/src/web/tests/knowledge_graph_test.php
```

```sh
docker compose exec -T -u www-data web php /home/judge/src/web/tests/adventure_http_test.php --fixtures
docker compose exec -T -u www-data web php /home/judge/src/web/tests/adventure_reward_test.php --fixtures
OJ_TEST_ORIGIN=http://127.0.0.1:18888 node web/tests/frontend-regression.mjs
```

覆盖凭证拒绝、匿名状态、HTML 转义、题目可见性、旧题 AC 战报、远征通关、题目下架、失效路线重建、影子提交编号边界、反例输入校验、首次 AC 去重及月度回顾；奖励回归另外覆盖每日路线固定、失效路线替换后的金币去重、并发替换和奖励日边界。
