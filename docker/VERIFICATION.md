## 验收发现并修正

1. 新建题目表单缺少后端要求的 postkey：复用现有令牌生成文件，不改变接口。
2. 初始管理员需要 `register_num=1` 才能通过现有登录审核。
3. OpenJDK 17 容器检测使用 `statfs`（x86_64 调用 137），旧 Java 白名单遗漏：
   只补该只读元数据调用，保留系统调用检查和其他语言规则。
4. 验收脚本重建容器后复用旧 HTTP socket：关闭该脚本的连接复用，完整重跑通过。
